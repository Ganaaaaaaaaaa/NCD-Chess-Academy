# NCD Chess Academy — v2

Монгол хэл дээрх академийн сайт, эцэг эхийн портал болон удирдлагын хэсэг.

## Гол файлууд
- `public/index.html` — үндсэн сайт, порталын бүтэц, модал цонхнууд
- `public/styles.css` — midnight navy / ivory загвар, responsive зохиомж
- `public/app.js` — 5 асуулттай тест, бүртгэл, портал, удирдлага
- `public/assets/coaches/` — хэрэглэгчийн өгсөн бодит зургууд
- `public/assets/NCD-36-Week-Curriculum.pdf` — 36 долоо хоногийн сургалтын төлөвлөгөө
- `worker/index.js` — Cloudflare Worker, нэвтрэлт шалгах, бүртгэл, порталын API
- `db/schema.ts`, `drizzle/` — өгөгдлийн сангийн схем, хувилбарт шилжилт
- `tests/` — API эрхийн хамгаалалт ба хэрэглэгчийн үйлдлийн шалгалт

## Бэлтгэх
Node.js 24+ ашиглана.

```sh
npm ci
npm test
npm run build
```

`dist/server/index.js` нь бүх статик нөөц болон API-г агуулсан ESM Worker. Өгөгдлийн сангийн логик холболт: `DB`. Sites нь миграци, өгөгдлийн сан, баталгаажсан хэрэглэгчийн header болон нэвтрэх урсгалыг удирдана. Стандарт Node HTTP сервер дээр баталгаажуулалтгүй header-уудыг интернэтээс хүлээн авч ажиллуулж болохгүй.

## Хэрэглэх
- `/` — үндсэн сайт, 5 асуулттай урьдчилсан тест, бүртгэл.
- `/portal` — зөвхөн өөрийн бүртгүүлсэн хүүхдийн мэдээлэл.
- `/admin` — академийн удирдлага; бүртгэлүүд, ирц, чансаа, 5 ур чадвар, сарын тайлан, даалгавар, хариултын зөвлөгөө, нийтлэх холбоо барих мэдээлэл.

Одоогийн админы баталгаажсан и-мэйл `worker/index.js` дотор `ADMIN_EMAIL`-ээр тохируулсан. Нэвтрэлт нь платформын ChatGPT sign-in. Утас/бүртгэлийн дугаар нь зөвхөн нэвтэрсэн хэрэглэгчийн өөрийн мэдээллээс хайх зориулалттай; өөрөө нэвтрэх нууц биш. Телеграм ашиглахгүйгээр бүртгэл удирдлагын хэсэгт сервер дээр хадгалагдана.

## Хадгалалт
Үндсэн бүртгэл, сурагчийн явц, даалгавар, хариулт D1-д хадгалагдана. Хувийн мэдээлэлтэй API нь no-store, хэрэглэгчийн эзэмшил болон админы эрхийг сервер дээр шалгана. POST/PATCH нь same-origin JSON хүсэлт шаарддаг. Бүртгэл давхар дарахад ижил ID-г ашиглана.

Хэрэглэгчийн хүсэлтээр браузерын localStorage-д theme, илгээхээс өмнөх ноорог, сүүлийн 10 бүртгэлийн хуулбар хадгална. Хуваалцдаг төхөөрөмж дээр browser site data-г цэвэрлэж болно. Серверт хадгалалт амжилттай болсны дараа л менежер холбогдох тухай баталгааг харуулна. Менежерийн бодит эргэх холбоо нь академийн ажилтны хийх үйл ажиллагаа.

## Агуулгын ялгаа ба ажиллуулах нөхцөл
- Багшийн цол, намтар нь хэрэглэгчийн өгсөн мэдээлэл. Зураг: team-1 Ган-Од; team-2 Баттүвшин; team-3 Хатанбаатар; team-4 Ган-Эрдэнэ.
- Нүүрний Т.Билгүүний мэдээлэл нь тод тэмдэглэсэн интерактив үзүүлэн; бодит сурагчийн бүртгэлд орохгүй.
- 11/12 ирц = 91.7%; чөлөөтэй 1 хичээлийг тусад нь үзүүлнэ.
- Дотоод чансаа нь FIDE чансаа биш. FIDE-д автомат илгээлт, Stockfish хөдөлгүүр, автомат төхөөрөмжөөр ирц илрүүлэх функц ороогүй; багш ирц, чансаа, үнэлгээ болон зөвлөгөөг удирдлагын хэсгээс оруулна.
- Хөтөлбөрийн PDF нь өгсөн чиглэлд тулгуурласан сургалтын төлөвлөгөө; FIDE-ээс баталсан гэрчилгээ гэж үзүүлэхгүй.
- Академийн утас, WhatsApp, Messenger, хаягийг `/admin`-д оруулмагц нийтэд зориулсан хэсэг болон шууд дуудлагын товчид харагдана. Мэдээлэлгүй холбоос зохиогоогүй.
- Сайт одоогоор эзэмшигчид нээлттэй хувийн эрхтэй. Эцэг эхчүүдэд ашиглуулахын өмнө сайтын үзэх эрхийг зориуд тохируулна.

## Шалгалт
API: бүртгэл, давхар илгээлт, бусдын мэдээллийг хориглох, админы эрх, ирц/чансааны үнэлгээ, даалгавар/хариулт/зөвлөгөө, холбоосын шалгалт.
UI: тестийн бүх босго, дахин эхлүүлэх, түвшин сонголт, theme, порталын хэсгүүд, зургийн дараалал, бүртгэлийн баталгаа.
PDF-ийн бүх хуудсыг зураг болгон шалгасан. Browser visual QA болон платформын жинхэнэ WebMCP гүйцэтгэлийн шалгалт энэ орчинд боломжгүй байсан.

## Компьютер дээр турших

```sh
npm ci
npm run dev
```

`http://localhost:3000` хаягаар нээнэ. Локал сервер зөвхөн loopback интерфэйс дээр ажиллаж, туршилтын админ болон санах ойн түр өгөгдөл ашиглана. Сервер зогсоход туршилтын өгөгдөл арилна. Энэ серверийг интернэтэд гаргахгүй; жинхэнэ сайт нь Sites-ийн нэвтрэлт, D1 хадгалалтыг ашиглана.
